**📁Проект: Система онлайн-записи для барбершопа**  

**Описание:** Комплексное проектирование информационной системы для автоматизации работы барбершопа: от сбора требований до проектирования базы данных.  

**Артефакты проектирования:**  

[**- Use Case: Актуализация расписания мастеров**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/Use%20Case_Актуализация_расписания_мастеров.pdf)  
Сформулированы функциональные требования к системе с точки зрения ролей (Клиент, Мастер, Менеджер) для понимания целевых сценариев использования.  

[**- User Story: Просмотр мастером своего расписания и отзывов**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/User%20Story_Мастер_просмотр_расписания.pdf)  
Описаны основные сценарии взаимодействия пользователей с системой (запись, управление расписанием, оплата, отзывы).
 
[**- Диаграмма потоков данных (DFD)**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/DFD.png)  
Схема логической архитектуры системы, детализирующая процессы и движение данных между клиентами, мастерами и менеджерами (от управления расписанием до оплаты и отчетов).  

[**- Диаграмма бизнес-процессов (Swimlane)**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/Sweamline_diagram.png)  
Модель целевого процесса (TO BE) онлайн-записи, показывающая последовательность действий и взаимодействие всех ролей — от публикации расписания до оплаты и отзывов. 

[**- Диаграмма жизненного цикла (State Diagram)**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/State_diagram.png)  
Модель текущего процесса (AS IS), описывающая все этапы жизни расписания — от создания менеджером и выбора мастера до согласования и итоговой публикации. 

[**- Диаграмма базы данных (ERD)**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/ER_diagram.png)  
Концептуальная схема реляционной базы данных, визуализирующая все сущности (клиентов, мастеров, записи, оплаты) и связи между ними для хранения информации.  

[**- Диаграмма бизнес-процесса "Сбор обратной связи" (BPMN)**](https://github.com/YuliMir/Yuliya_Mironova/blob/main/BPMN.png)  
Модель процесса обработки отзывов, в которой система автоматически инициирует запрос клиенту, сохраняет полученный отзыв в БД, а менеджер анализирует результат и регистрирует инцидент при негативном опыте для дальнейшего расследования.
