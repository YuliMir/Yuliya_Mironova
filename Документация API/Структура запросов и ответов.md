# Описание элементов запроса/ответа

| № | Вариант интеграции | Назначение по бизнесу | Метод | Направление | Запрос/ответ | ID элемента | Название по бизнесу | Тип | Размерность | Обязательность | Соответствие | Комментарии |
|---|--------------------|-----------------------|-------|-------------|--------------|-------------|---------------------|-----|-------------|----------------|--------------|-------------|
| 1 | Запрос к БД – проверка номера | Проверить наличие номера, чтобы не создать дубликат | GET | Исходящее | Запрос | phone | Номер телефона | string | 10 | Да | client.phone | — |
| 2 | Запрос к БД – проверка нового номера | Проверить наличие номера, чтобы не создать дубликат | GET | Исходящее | Запрос | phone | Номер телефона | string | 10 | Да | client.phone | Только цифры, без кода |
| 3 | Внутренний вызов – генерация пароля | Сгенерировать одноразовый пароль для доступа клиента | — | Исходящее | Запрос | — | — | — | — | — | — | Внутренний вызов, тела нет |
| 4 | REST API – отправка СМС | Отправить СМС с паролем клиенту | POST | Исходящее | Запрос | phone, message | Номер телефона, Текст сообщения | string | 10, 160 | Да | sms.phone, sms.text | Номер только цифры |
| 5 | Запрос к БД – сохранение клиента | Создать карточку клиента для скидок и связи | POST | Исходящее | Запрос | name, phone | Имя, Номер телефона | string | 50, 10 | Да | client.name, client.phone | — |
| 6 | Общая БД – справочник «Роли сотрудника» | Хранить роли в одном месте для всей сети | GET | Входящее | Запрос | employeeId | Идентификатор сотрудника | integer | 10 | Да | employees.id | — |
| 7 | Общая БД – справочник «Каналы связи» | Доступ к каналам для выбора формата связи | GET | Входящее | Запрос | channelCode | Код канала | string | 3 | Да | channels.code | Значение из справочника |
| 8 | Общая БД – справочник «Статусы клиента» | Доступ к статусам для всех менеджеров | GET | Входящее | Запрос | statusCode | Код статуса | string | 10 | Да | statuses.code | Значение из справочника |

## Ответы для всех запросов

| Код | Тело ответа |
|-----|-------------|
| 200 OK | { "status": "success", "data": {...} } |
| 400 Bad Request | { "error": "Неверный формат" } |
| 404 Not Found | { "error": "Запись не найдена" } |
| 500 Internal Server Error | { "error": "Внутренняя ошибка" } |
