- Сущность/класс: Client
- Вложенный блок/множественность: нет / 1
- Элемент/поле: phoneNumber
- Тип данных: string
- Размерность: 10
- Обязательность: Да
- Условия, ограничения: только цифры, 10 символов

- Название по бизнесу: Номер телефона

- Обязательность: Да
