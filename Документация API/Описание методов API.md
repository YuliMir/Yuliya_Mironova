# Exercise 04 — Определение и описание методов

## Набор «вопрос-ответ» по интеграциям

| Интеграция | Вопрос | Ответ |
|------------|--------|-------|
| Проверка номера | Существует ли клиент с таким номером? | Да / Нет |
| Повторная проверка номера | Существует ли клиент с таким номером? | Да / Нет |
| Генерация пароля | Сгенерирован ли пароль? | Пароль: {значение} |
| Отправка СМС | Отправлено ли СМС? | Статус отправки |
| Сохранение клиента | Сохранён ли клиент? | ID клиента |
| Роли сотрудника | Запрос роли текущего сотрудника | Роль: «Менеджер» |
| Каналы связи | Запрос доступных каналов связи | Список: СМС, VK, Telegram, WhatsApp |
| Статусы клиента | Запрос доступных статусов клиента | Список: Новый, Заблокированный |

## Определение HTTP-методов

| Справочник | CRUD операция | Безопасный метод | Идемпотентный метод | HTTP-метод |
|------------|---------------|------------------|---------------------|------------|
| Проверка номера | Чтение | Нет | Да | GET |
| Повторная проверка номера | Чтение | Нет | Да | GET |
| Генерация пароля | Создание | Нет | Нет | POST |
| Отправка СМС | Создание | Нет | Нет | POST |
| Сохранение клиента | Создание | Нет | Нет | POST |
| Роли сотрудника | Чтение | Нет | Да | GET |
| Каналы связи | Чтение | Нет | Да | GET |
| Статусы клиента | Чтение | Нет | Да | GET |

## Описание запросов и ответов

### 1. Проверка номера

**Запрос:**

- Метод: GET
- URL: /api/clients/check-phone
- Параметры: номер телефона (phone)
- Тело запроса: отсутствует

**Ответы:**

- Успешный: 200 OK, { "exists": false }
- Неуспешный: 400 Bad Request, { "error": "Неверный формат" }

### 2. Повторная проверка номера

**Запрос:**

- Метод: GET
- URL: /api/clients/check-phone
- Параметры: номер телефона (phone)
- Тело запроса: отсутствует

**Ответы:**

- Успешный: 200 OK, { "exists": false }
- Неуспешный: 400 Bad Request, { "error": "Неверный формат" }

### 3. Генерация пароля

**Запрос:**

- Метод: POST
- URL: /api/auth/generate-password
- Параметры: отсутствуют
- Тело запроса: отсутствует

**Ответы:**

- Успешный: 200 OK, { "password": "abc1234" }
- Неуспешный: 500 Internal Server Error, { "error": "Ошибка генерации" }

### 4. Отправка СМС

**Запрос:**

- Метод: POST
- URL: /api/sms/send
- Параметры: отсутствуют
- Тело запроса: { "phone": "1234567890", "message": "Ваш пароль: abc1234" }

**Ответы:**

- Успешный: 200 OK, { "status": "sent" }
- Неуспешный: 502 Bad Gateway, { "error": "Сервис недоступен" }

### 5. Сохранение клиента

**Запрос:**

- Метод: POST
- URL: /api/clients
- Параметры: отсутствуют
- Тело запроса: { "name": "Иван", "phone": "1234567890" }

**Ответы:**

- Успешный: 201 Created, { "id": 1 }
- Неуспешный: 400 Bad Request, { "error": "Неверные данные" }

### 6. Справочник «Роли сотрудника»

**Запрос:**

- Метод: GET
- URL: /api/employees/{id}/role
- Параметры: id — идентификатор сотрудника
- Тело запроса: отсутствует

**Ответы:**

- Успешный:
  - Код: 200 OK
  - Тело: { "role": "Менеджер" }
- Неуспешный:
  - Код: 404 Not Found
  - Тело: { "error": "Сотрудник не найден" }

### 7. Справочник «Каналы связи»

**Запрос:**

- Метод: GET
- URL: /api/channels
- Параметры: наименование канала
- Тело запроса: отсутствует

**Ответы:**

- Успешный:
  - Код: 200 OK
  - Тело: [ { "code": "SMS", "name": "СМС", "active": true } ]
- Неуспешный:
  - Код: 404 Not Found
  - Тело: { "error": "Канал не найден" }

### 8. Справочник «Статусы клиента»

**Запрос:**

- Метод: GET
- URL: /api/statuses
- Параметры: наименование статуса
- Тело запроса: отсутствует

**Ответы:**

- Успешный:

- Неуспешный:
  - Код: 404 Not Found
  - Тело: { "error": "Статус не найден" }
