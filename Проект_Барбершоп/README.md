# Система онлайн-записи для барбершопа

Комплексное проектирование информационной системы: от сбора требований до проектирования БД и интеграций.

## Структура проекта

| Этап | Папка | Артефакты |
|------|-------|-----------|
| 1. Требования | `01_Требования/` | Use Case, User Story |
| 2. Процессы | `02_Моделирование_процессов/` | DFD, Swimlane, диаграмма состояний, BPMN |
| 3. База данных | `03_Проектирование_БД/` | ER-диаграмма |
| 4. Интеграции | `04_Проектирование_интеграций/` | HTTP-методы, поля, маппинг, ошибки |
